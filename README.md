# 📊 Reporte Comercial: 
contiene metricas calculadas usando DAX para encontrar valores de indicadores como ventas, utilidad, entre otros. 
Existe una tabla calendario creada imprescindible para hacer análisis de time intelligence donde se puede ver cómo varia un KPI en el tiempo. 
El archivo cuenta con variedad de visuales utilizadas para analizar tendencia, utilidad acumulada, relación ventas - utilidad por tier, y cruces temporales. 

# 🕵🏻 Principal Hallazgo: 
Existen dos categorías de las cuatro que, a pesar de tener gran volumen de venta, aportan significativamente a la perdida de utilidad. 
El negocio opera prácticamente entorno al punto de equilibrio, oscilando entre ganar unos meses y perder en otros; el gráfico waterfall muestra esta volatilidad. 

# 🚀 Accionables: 
Ya que el reporte permite ver la relación del volumen de ventas con la utilidad, vale la pena investigar si los precios están bien definidos, qué alternativas existen para bajar costos, o si deberiamos continuar vendiendo productos que afectan a la utilidad.
